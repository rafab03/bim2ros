En esta carpeta se generarán los JSON con la información de los vértices locales, posición y orientación, y los parámetros físicos de cada elemento móvil. También se generará automáticamente un JSON con el ínice correspondiente a cada link móvil específico, para que cuando el nodo de control se suscriba al al tópico /movable_objects/door_angles_real pueda identificar el link correcto en el tópico y aplicar el esfuerzo correspondiente sobre dicho elemento.

También se generarán los archivos necesarios para la publicación del mapa.
